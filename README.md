# AutoSkrin — автоматические скриншоты при изменении экрана

AutoSkrin следит за выбранной областью экрана и сам делает скриншот, как только
картинка в ней меняется. Снимки сохраняются файлами в папку и/или **сразу
дописываются в документ Word**. Так удобно конспектировать лекции и вебинары:
слайды попадают в конспект сами, а вы печатаете заметки рядом.

## Возможности

- **Выбор области как в «Ножницах»**: экран затемняется, область выделяется мышью,
  рядом видны координаты и размер. Поддерживаются несколько мониторов и масштаб
  Windows 125 % / 150 %.
- **Детекция изменений**: область проверяется с настраиваемой частотой
  (по умолчанию раз в секунду), кадры сравниваются попиксельно.
  - *Порог чувствительности*: сколько процентов пикселей должно измениться.
  - *Допуск цвета пикселя*: мелкий шум (сжатие видео, мерцание) не считается изменением.
- **Куда сохранять — на выбор**:
  - файлы **PNG** или **JPG** в папку, имя с временной меткой: `screenshot_2024-01-15_14-30-25.png`;
  - **документ Word (.docx)**: каждый снимок дописывается в конец с подписью
    «Скриншот 5 — 15.01.2024 14:30:25». Если документ открыт в Microsoft Word,
    снимки появляются в нём сразу, и рядом можно печатать свои заметки;
  - или в оба места сразу.
- Сохранять можно **выбранную область, монитор с областью или все мониторы**.
- **Таймер**: мониторинг выключится сам **через** заданное время (например, 1:30 —
  длительность пары) или **в** заданное время (например, в 15:30).
- **Защита от спама**: минимальный интервал между снимками. Изменение во время паузы
  не теряется: снимок делается сразу после её окончания.
- **Управление**: «Старт/Стоп», «Выбрать область», выбор папки и документа, счётчик
  снимков, журнал событий с временем.
- **Системный трей**: пауза/старт, выбор области, открыть папку, выход; уведомление
  о каждом скриншоте (отключается).
- **Горячая клавиша `Ctrl+Alt+S`** ставит мониторинг на паузу и снимает с неё, даже когда
  окно свёрнуто. Сочетание можно поменять прямо в окне программы.
- **Настройки запоминаются**; можно запускать мониторинг сразу при старте программы
  и запускать программу вместе с Windows.

## Установка

### Способ 1: установщик (рекомендуется)

Скачайте **[AutoSkrin-Setup.exe](https://github.com/Cosiposha-I/AutoSkrin/releases/latest/download/AutoSkrin-Setup.exe)**
и запустите. Мастер установки позволяет всё настроить под себя:

| Шаг мастера | Что можно выбрать |
|---|---|
| Режим установки | только для себя (права администратора не нужны) или для всех пользователей |
| Папка установки | любая папка, например `D:\Программы\AutoSkrin` |
| Компоненты | только программа или программа + исходный код на Python |
| Меню «Пуск» | имя папки с ярлыками или «не создавать папку» |
| Дополнительно | ярлык на рабочем столе, запуск вместе с Windows |
| Куда сохранять скриншоты | папка и/или документ Word, что снимать, формат PNG/JPG |
| Как замечать изменения | интервал проверки, порог, мин. интервал между снимками, уведомления, трей |
| Обновление | оставить текущие настройки программы или заменить их выбранными |

Перед установкой мастер показывает сводку всех выбранных параметров.

**Обновление:** просто запустите установщик новой версии — он найдёт прежнюю и заменит её.
Удалять старую версию заранее не нужно.

> Если Windows покажет окно «Windows защитил ваш компьютер» (так бывает с программами
> без платной цифровой подписи), нажмите **«Подробнее» → «Выполнить в любом случае»**.

#### Тихая установка (для администраторов)

Все параметры мастера можно задать в командной строке:

```
AutoSkrin-Setup.exe /VERYSILENT /CURRENTUSER /DIR="D:\Программы\AutoSkrin"
    /COMPONENTS="main,source" /TASKS="desktopicon,autorun"
    /SHOTSDIR="D:\Лекции" /SAVETODOCX=1 /DOCX="D:\Лекции\Конспект.docx"
    /FORMAT=jpg /INTERVAL=1 /THRESHOLD=1 /MININTERVAL=5
```

| Параметр | Значения | Описание |
|---|---|---|
| `/CURRENTUSER`, `/ALLUSERS` | — | для себя / для всех пользователей |
| `/DIR="путь"` | папка | куда установить программу |
| `/GROUP="имя"`, `/NOICONS` | — | папка в меню «Пуск» / без неё |
| `/COMPONENTS="…"` | `main`, `source` | состав установки |
| `/TASKS="…"` | `desktopicon`, `autorun` | ярлык на рабочем столе, автозапуск с Windows |
| `/SAVETOFOLDER=` | `1` / `0` | сохранять файлы в папку (по умолчанию 1) |
| `/SHOTSDIR="путь"` | папка | папка для скриншотов |
| `/SAVETODOCX=` | `1` / `0` | дописывать скриншоты в документ Word (по умолчанию 0) |
| `/DOCX="путь"` | файл .docx | документ Word |
| `/CAPTURE=` | `region`, `screen`, `all` | что снимать |
| `/FORMAT=` | `png`, `jpg` | формат файлов |
| `/INTERVAL=`, `/THRESHOLD=`, `/MININTERVAL=` | числа | интервал проверки (с), порог (%), мин. интервал между снимками (с) |
| `/NOTIFY=`, `/AUTOSTARTMON=`, `/TRAY=` | `1` / `0` | уведомления, мониторинг сразу при старте, сворачивание в трей |
| `/KEEPSETTINGS=` | `1` / `0` | при обновлении оставить текущие настройки (по умолчанию 1) |

Тихое удаление: `unins000.exe /VERYSILENT /DELETESETTINGS=1` (последний параметр
удаляет и настройки).

### Способ 2: переносная версия без установки

Скачайте **[AutoSkrin-Portable.zip](https://github.com/Cosiposha-I/AutoSkrin/releases/latest/download/AutoSkrin-Portable.zip)**,
распакуйте в любую папку и запустите `AutoSkrin\AutoSkrin.exe`.

### Способ 3: из исходного кода

1. Скачайте код: зелёная кнопка **Code → Download ZIP** на странице репозитория,
   распакуйте в любую папку.
2. Дважды щёлкните **`install.bat`**. Скрипт сам найдёт Python 3.10+ (или поставит его
   через `winget`), установит библиотеки и создаст ярлык на рабочем столе.
3. Дальше запускайте программу ярлыком или файлом **`run.bat`**.

Вручную: `pip install -r requirements.txt`, затем `python main.py`.

### Собрать установщик самому

Дважды щёлкните **`build_installer.bat`**: в папке `dist` появятся `AutoSkrin-Setup.exe`
и `AutoSkrin-Portable.zip`. Для установщика нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)
(скрипт попробует поставить его через `winget`).

Кроме того, установщик собирается и проверяется автоматически на GitHub (Actions)
после каждого изменения кода и публикуется в разделе
[Releases](https://github.com/Cosiposha-I/AutoSkrin/releases).

## Удаление

Скриншоты и документы Word при удалении не трогаются никогда.

- **Обычный способ:** «Параметры → Приложения → AutoSkrin → Удалить», либо ярлык
  **«Удалить AutoSkrin»** в меню «Пуск» или в папке программы. Деинсталлятор спросит,
  удалять ли настройки программы.
- **Полная очистка любой версии:** скачайте
  **[AutoSkrin-Uninstall.bat](https://github.com/Cosiposha-I/AutoSkrin/releases/latest/download/AutoSkrin-Uninstall.bat)**
  (он же `uninstall.bat` в исходном коде) и запустите двойным щелчком. Он сам найдёт
  все установленные версии (для себя и для всех пользователей), версию из исходного кода
  (`install.bat`), автозапуск и ярлыки, покажет список и после подтверждения удалит.
  Параметры для автоматического запуска: `/y` — не спрашивать, `/settings` — удалить
  настройки, `/source` — удалить папки с исходным кодом.
- **Переносная версия (ZIP):** просто удалите её папку.

## Как пользоваться

1. Нажмите **«Выбрать область»** и выделите мышью нужный участок экрана
   (`Esc` или правая кнопка мыши — отмена).
2. В блоке **«Куда сохранять»** отметьте папку и/или документ Word, выберите, что снимать,
   и формат.
3. При желании включите **таймер**, например «остановить мониторинг через 1:30».
4. Нажмите **«Старт»**. Изменения в области будут сохраняться автоматически, а в журнале
   появятся записи о каждом снимке.
5. Закрытие окна сворачивает программу в трей. Полный выход — пункт «Выход» в меню значка в трее.

### Конспект лекции в Word

1. Отметьте **«Документ Word»** и нажмите **«Выбрать документ…»**: укажите существующий
   документ (снимки допишутся в конец) или введите имя нового.
2. Нажмите **«Открыть в Word»**: документ откроется (если его нет, он будет создан).
3. Выберите область со слайдами, включите таймер на время лекции и нажмите **«Старт»**.
4. Каждый новый слайд появится в конце документа с подписью. Печатайте свои заметки
   под снимками и сохраняйте документ как обычно (`Ctrl+S`).

Если документ открыт не в Microsoft Word, а в другой программе, и файл занят, снимки
ждут в очереди и попадут в документ, как только его закроют. Если документ так и не
освободился до остановки мониторинга, снимки не пропадут: они останутся в папке
со скриншотами или будут перенесены в папку рядом с документом.

### Подбор чувствительности

- Внизу окна видно, на сколько процентов изменилась область при последней проверке.
  Поставьте порог немного выше значений, которые вы видите, когда «ничего не происходит».
- Если в области идёт видео или есть мелкое мерцание, увеличьте **допуск цвета пикселя**
  (например, до 20–40).
- Если снимков слишком много, увеличьте **минимальный интервал между снимками**.
- Если уведомления Windows всплывают внутри отслеживаемой области, они сами вызывают
  срабатывания: отключите уведомления о скриншотах или выберите другую область.

## Настройки

Настройки сохраняются автоматически в `%APPDATA%\AutoSkrin\settings.json`
(там же лог `autoskrin.log`). Параметры, выбранные в установщике, лежат в файле
`defaults.json` в папке программы и применяются при первом запуске.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `save_to_folder` | `true` | Сохранять файлы в папку |
| `save_dir` | `Изображения\AutoSkrin` | Папка для скриншотов |
| `save_to_docx` | `false` | Дописывать скриншоты в документ Word |
| `docx_path` | `Изображения\AutoSkrin\Конспект.docx` | Документ Word |
| `docx_captions` | `true` | Подпись «Скриншот N — дата, время» над снимком |
| `region` | — | Область: `left`, `top`, `width`, `height` в пикселях экрана |
| `interval_sec` | `1.0` | Интервал проверки, секунд (0.1–60) |
| `threshold_percent` | `1.0` | Порог: процент изменённых пикселей (0.01–100) |
| `pixel_tolerance` | `12` | На сколько (0–255) должен измениться цвет пикселя |
| `min_interval_sec` | `5.0` | Минимальная пауза между снимками, секунд |
| `capture_mode` | `region` | Что снимать: `region`, `screen` (монитор) или `all` (все мониторы) |
| `image_format` | `png` | `png` или `jpg` |
| `jpeg_quality` | `90` | Качество JPG (10–100) |
| `timer_enabled` | `false` | Таймер автоматической остановки |
| `timer_mode` | `after` | `after` — через заданное время, `at` — в заданное время |
| `timer_minutes` | `90` | Для `after`: через сколько минут остановить |
| `timer_at` | `18:00` | Для `at`: во сколько остановить |
| `notifications_enabled` | `true` | Уведомление в трее о каждом скриншоте |
| `autostart_monitoring` | `false` | Запускать мониторинг сразу при старте программы |
| `minimize_to_tray` | `true` | Сворачивать в трей при закрытии окна |
| `hotkey` | `Ctrl+Alt+S` | Горячая клавиша паузы/старта |

Параметры запуска: `AutoSkrin.exe --minimized` (свёрнутым в трей), `--start` (сразу начать мониторинг).

## Структура проекта

```
AutoSkrin/
├── main.py               # точка входа: запуск, один экземпляр, лог, самопроверка
├── monitor.py            # логика отслеживания: захват, сравнение кадров, сохранение, таймер
├── region_selector.py    # выбор области с затемнением и рамкой
├── settings.py           # работа с конфигом (JSON), настройки установщика, автозапуск Windows
├── ui.py                 # интерфейс: главное окно, трей, горячая клавиша
├── word_doc.py           # запись скриншотов в документ Word
├── requirements.txt      # зависимости
├── install.bat           # установка из исходников (Python, библиотеки, ярлык)
├── run.bat               # запуск из исходников
├── build_installer.bat   # сборка установщика на своём ПК
├── uninstall.bat         # полное удаление любой версии AutoSkrin
├── assets/               # иконка программы
├── installer/            # скрипт установщика Inno Setup (страницы мастера, параметры)
├── tools/                # сборка (build.py), проверка установщика, генерация иконки
├── tests/                # автотесты (pytest)
└── .github/workflows/    # автоматическая сборка и проверка установщика на GitHub
```

Технологии: Python 3.10+, PyQt6, mss, numpy, Pillow, python-docx, pywin32;
сборка — PyInstaller и Inno Setup.
